Official Helm Repository

Karpenter Pulse

Observability & Autoscaling Dashboard for Kubernetes Karpenter

🚀 Quick Start: Add Helm Repository

Add the Karpenter Pulse Helm chart repository to your Helm client:

# Add repository
helm repo add karpenter-pulse https://igorkurylo1988.github.io/karpenter-pulse/

# Fetch latest charts
helm repo update

📦 Install Karpenter Pulse

Deploy the complete Karpenter Pulse dashboard (UI + Backend + RBAC) into your cluster:

# Install full application suite into 'karpenter-pulse' namespace
helm install karpenter-pulse karpenter-pulse/karpenter-pulse \
  --namespace karpenter-pulse \
  --create-namespace

📊 Available Helm Charts

karpenter-pulse

Main umbrella chart orchestrating both the frontend UI and backend Go API services.

backend

Subchart deploying the Go API service, Karpenter client informers, and cluster RBAC permissions.

frontend

Subchart deploying the React dashboard powered by Vite, TailwindCSS, and Nginx.

Source code and documentation available on GitHub.
