# AGENTS.md

Welcome to the project automation workspace. The specialized engineering agent profiles are managed inside the `.agents/` directory.

## Engineering Team Directory

- **[@Product Engineer](.agents/product_engineer.md):** Technical Product Manager and Feature Architect.
- **[@Backend Engineer](.agents/backend_engineer.md):** Go Microservices and Cloud-Native Developer.
- **[@Frontend Engineer](.agents/frontend_engineer.md):** Responsive Dashboards and Recharts UI Architect.
- **[@Release Engineer](.agents/release_engineer.md):** CI/CD Pipeline and Helm Package Specialist.


## Global Rules
- Before starting a multi-layer ticket, invoke the `@Product Engineer` to build the feature blueprint.
- All code generated by any profile must comply with the internal rules defined in their respective linked manifest files.
